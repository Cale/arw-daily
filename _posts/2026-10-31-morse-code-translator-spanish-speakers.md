*The following is a message from [Código Morse](https://codigo-morse.com/):*

A new free online Morse code translator has launched at [codigo-morse.com](https://codigo-morse.com/), built specifically for Spanish speakers. It translates text to Morse and back with real audio playback, adjustable speed in WPM and tone, and full support for Spanish characters such as Ñ, Á, É, Ó and Ü. It includes a printable alphabet chart, numbers, common phrases and an SOS guide. No signup is needed and it works entirely in the browser, which makes it handy for beginners learning CW and for teachers introducing Morse code in class.

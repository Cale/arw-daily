*The following is a message from the creator of IU0VYT Flash:*

[IU0VYT Flash](https://iu0vyt.github.io/IU0VYT/), a free and open source (GPL-3.0) Windows program written by Italian ham Daniele Bonifazi, IU0VYT, has reached version 4.45. It reads and writes channels and zone names of 623 handheld and mobile radio models of 54 brands, the settings of 556 of them, and updates the firmware of 58.

New in 4.45: channels and zones for the AnyTone AT-D868UV / AT-D878UV family and the BTECH DMR-6X2 over the radio's USB cable, plus TYT MD-UV380 / MD-UV390 / MD-2017 / MD-9600 and Retevis RT3S / RT82 with the original firmware.

The program identifies the connected radio by itself, makes a backup before every write and verifies it afterwards, copies channels between radios of different brands and opens and saves CHIRP .img and CSV files. The interface, the guide and, from this week, the release notes are available in 13 languages.

Protocols were rebuilt for interoperability and tested against simulated radios: the test suite includes 918 structure comparisons and 381 reads and writes identical to CHIRP. The newest radios have not yet been tried on real hardware, so the author asks owners to start with a read-only test and to report results.

*The following is a press release from [QSL Shack](https://qslshack.com/):*

*Just two weeks after launch, QSL Shack releases a barrage of new features and enhancements including a logging API, “Quick QSO”, enhanced feed functions, improved QSO filtering with mass updates, bigger imports, a profile sharing function, and a fully redesigned Support Center.*
 
**BOYNTON BEACH, Fla., November 15, 2026** - QSL Shack ([qslshack.com](https://qslshack.com/)), the free social platform for the amateur radio community, announces the release of its logging software API. Operators who log in a desktop program no longer need to export and upload ADIF files: each contact goes into their QSL Shack logbook as it is logged. The release follows the platform's [public launch](https://daily.hamweekly.com/2026/10/qsl-shack-launches-social-network-for-ham-radio-operators/) on November 1 and rounds out a series of features added in its first two weeks.
 
Many operators, especially contesters, DXers and anyone with a large log, keep their station log in dedicated logging software. QSL Shack's API lets that software send each QSO directly to a member's logbook. Members can create an API key for a logbook with the click of a button and enter it in their program. The API is proven with Log4OM and should work directly with any Cloudlog-compatible logging program, using the same address, key and station settings those programs already ask for. In testing with Log4OM, contacts arrived in QSL Shack about a minute after they were logged.
 
Every contact sent this way is treated like any other: it is matched against the other station's log for automatic confirmation, a contact already in the logbook is not added twice, and each key writes to one logbook only and can be revoked at any time. The API is free, like everything else on QSL Shack.
 
In addition to the Logging API, QSL Shack has added the following features to its already robust platform:
 
**Quick QSO** – Operators logging by hand can tick one box to save a QSO “template” that reduces the fields needed to log a QSO to as little as only the worked callsign. There are some "Quick Settings" for sent/received RST and to change frequency band & mode and, with a single click, the member can exit Quick QSO mode to access the full settings.
 
**Background Imports & Mass Updates** – ADIF files up to 64 MB can now be uploaded, and large logs import in the background. The member can do other things and will receive a notification when the import completes. QSL Shack also improved its QSO filtering and added a mass update feature that lets members filter their QSOs by multiple fields concurrently, select which fields to update and with what information, and update all matching QSOs accordingly, with a preview of what gets updated and replaced before any changes are confirmed.
 
**Feed Improvements** – QSL Shack also released numerous enhancements to its feed. Posts can carry hashtags, and each tag opens a page of every post that uses it, making it easy to follow a topic such as #POTA or #SSB across the community. Members may now upload up to ten pictures a post, and any picture opens full size with one click. Additionally, comments and replies now have an emoji picker, reactions, pictures, multi-line text, and editing after posting.
 
**Profile Sharing** – Members can create a public profile page with a ready-made picture for Facebook, X and LinkedIn, to invite friends and club members to find them on QSL Shack.
 
**Completely Redesigned Support Center** – Detailed setup guides for every feature are organized in a searchable Support Center at qslshack.com/support, open to everyone.
 
“We’ve been releasing new features and functionality at a truly incredible pace,” said Jonathan Castleman, KN4DZD, founder of QSL Shack. “Some of these have been planned for some time, but many have been in response to requests from current members, and member feedback plays a critical role in our development schedule,” Castleman added.
 
## Availability
 
The logging software API and every feature above are available now to all QSL Shack members at qslshack.com. Membership is free, with no credit card required. Operators can claim their callsign at qslshack.com/register. Setup guides are in the Support Center at qslshack.com/support, and connecting a logging program is explained at qslshack.com/support/logging-software.

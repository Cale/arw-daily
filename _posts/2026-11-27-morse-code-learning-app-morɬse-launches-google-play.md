*The following is a message from morɬSE:*

[morɬSE](https://play.google.com/store/apps/details?id=com.tiglobal.morse), a free Android app for learning and practicing Morse code (CW), has launched on Google Play. The app is developed by Gabriel Tanase, an independent developer from Romania, and has been tested for several weeks by licensed radio amateurs before launch.

The app teaches CW using the Koch method with adjustable Farnsworth spacing. It also includes:

- radiogram copying practice
- an adaptive daily challenge with streaks
- a competitive mode for letters and digits, with ranks from Silver to Legend
- an English and Romanian interface

In its first days, morɬSE has reached users in more than 20 countries. It is free to [download](https://play.google.com/store/apps/details?id=com.tiglobal.morse), with an optional Pro version.
